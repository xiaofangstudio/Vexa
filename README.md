## ✏️ 一句话说清做什么

三件事：**拉线成形、编排成图、导出成稿。**

- **拉线成形**——钢笔工具笔笔跟手，直线一拖即出，自由铅笔松手自动抽稀 + 平滑；宽度工具在描边上拖出粗细变化，中心两侧同调、方块柄单侧调宽，双击删宽度点；橡皮按住一擦，填充图形挖洞、描边线条断开；锚点、手柄、布尔运算（联合 / 减去 / 相交 / 排除）都是基本功；剪刀工具点锚点切线，路径还能偏移、描边转轮廓、平滑
- **编排成图**——图层、编组、对齐分布、渐变与描边、吸管取色、画布拖渐变方向、混合模式与剪切蒙版、字符面板（字体/字号/行距/字距/粗斜体/对齐/横纵缩放/基线）、画板能直接在画布上拖着开、拖着改，路径用平滑工具一刷就顺；画布重绘合并到一帧，拖动不闪
- **导出成稿**——SVG / PNG / PDF 一键导出，倍率随便选，给开发给印刷都不虚

## 🧭 界面

- **7 个主菜单**：文件 / 编辑 / 对象 / 文字 / 视图 / 窗口 / 帮助，文字与窗口操作不用再翻右侧面板找。
- **7 组双列工具轨**：选择、路径与笔、修形、颜色、形状、画板、视图；悬停有“工具名 + 快捷键”。
- **上下文选项栏**：当前工具、已选数量、画板尺寸、填充/描边、网格与吸附跟着工具走，不再堆一排死按钮。
- **可收起右侧面板**：属性 / 图层分页停靠，收起后画布自动补位并保持画板居中；画布右键直接出对象菜单。
- **有呼吸的过渡**：欢迎页进入编辑器的淡入、关闭文档的退场、面板开合和图层切换都有短过渡，`prefers-reduced-motion` 下自动收敛。

## ❓ 常见问题

**为什么自己做而不用 Inkscape？**
Inkscape 很强，但界面老、中文体验一般、GTK 手感和 Windows 原生不搭。Vexa 从第一天就是全中文、Windows 优先、按小方工作室的手感标准来做的。

**什么时候能用上？**
立项规格已定稿，进展看仓库动态。

**名字什么意思？**
VECtor + 家族后缀 -a，和 Chit、Scheda、Kinexa 一个命名家族。
