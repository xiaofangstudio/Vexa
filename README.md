## ✏️ 一句话说清做什么

三件事：**拉线成形、编排成图、导出成稿。**

- **拉线成形**——钢笔工具笔笔跟手，直线一拖即出，自由铅笔松手自动抽稀 + 平滑；宽度工具在描边上拖出粗细变化，中心两侧同调、方块柄单侧调宽，双击删宽度点；橡皮按住一擦，填充图形挖洞、描边线条断开；锚点多选（拖框、Shift 加点、同步拖动、方向键微移、`Delete` 删点）、开放端点连接（含跨路径节点，`Ctrl+J`）与六向锚点对齐、水平/垂直等距分布、手柄、路径查找器（联合 / 相交 / 减去 / 排除 / 分割 / 修边 / 合并 / 裁剪 / 轮廓）都是基本功；剪刀工具点锚点切线，路径还能偏移、描边转轮廓、平滑
- **导入起稿**——SVG 直接导成可编辑路径与文字：矩形/圆/多边形/直线、分组变换、线性/径向渐变、色标透明度、`fill-opacity` / `stroke-opacity`、`href` 渐变继承、`<use>` 引用、`<clipPath>` 组裁切（嵌套裁切取交集）与 symbol viewBox/宽高缩放都保留；`<text>` / `<tspan>` 保留字体、字号、字距与渐变填充，裁切里的字也能直接选中改；位图可以走本机 VTracer 描摹成路径。Vexa 画完导出 SVG，直接在 Groma 里导入，路径、渐变、描边、文本与内嵌图片都会保留；Vexa 只打开 `.vex` / `.svg`，不导入 Groma 工程；PNG/JPG 不归 Vexa，交给 Strata
- **编排成图**——可展开组的图层树，任意层级都能拖：组内排序、把子层拖出组、把顶层拖入组，落点有线/胶囊提示；Ctrl/Shift 多选后批量显隐/锁定；图层可搜名称或类型、按 6 色标记筛选，属性坞给单层/多层统一打标；属性坞对单选和多选都显示 X/Y/W/H，组递归缩放、文字精确落到目标宽高，附旋转 ±90°、水平/垂直翻转与数值/Ctrl 拖边柄斜切（±80°，Shift 15° 吸附）；实色填充、描边、画板底色带 12 色板与最近 10 色；文档级全局色/专色，色板可新建、改名改色、删除与导入导出 JSON，链接的填充/描边随色板同步；编组、对齐分布、渐变与描边、吸管取色、画布拖渐变方向、混合模式与剪切蒙版、字符面板（字体/字号/行距/字距/粗斜体/下划线/删除线/对齐/横纵缩放/基线）、横/直排切换（直排逐字向下、换列向左，区域自动换列，汉字正立、拉丁随列旋转，标点右上移与括号旋转）、区域文字避头尾（行首不落收尾标点、行末不落起首标点，分栏同步）、区域文字（拖框创建、框内自动换行、框宽高与溢出标记、首行缩进/段距/垂直对齐、1–6 栏分栏与栏距、单点互转）、路径文字（选中路径或路径+文字后“文字 → 转为路径文字”，文字按路径弧长与切线逐字旋转，属性坞可调起点与左右侧，SVG/PDF/.vex 同步）、文字转路径（`Ctrl+Shift+O` 或属性坞“转路径”，按本机真实字形轮廓生成可编辑路径，继承填充/透明度/混合/标记并支持撤销）、画板能直接在画布上拖着开、拖着改，画板面板内置 6 个尺寸预设，支持自定义预设保存/导入与删除、一键适配内容（计入描边宽度、忽略隐藏层）、复制画板连内容、上下换序；文件菜单的“文档设置”可改文档名、当前画板名/尺寸/背景，勾选后把尺寸与背景同步到全部画板（画板名仍只改当前板），带 1–20000 px 校验与单次撤销，路径用平滑工具一刷就顺；线性/径向渐变支持多色标增删、独立透明度、插值中点与画布色标直拖，描边端帽与拐角连接可切；拖动、画线、铅笔、橡皮只重绘画布，平移/缩放每帧不惊动 React 壳层，光标坐标只更新状态栏文本，属性坞与图层名输入在松手/失焦后统一提交；画布重绘合并到一帧，拖动不闪
- **导出成稿**——SVG / PNG / PDF 一键导出，倍率随便选，给开发给印刷都不虚；PDF 每个画板一页，原生线性/径向渐变、文字轮廓与透明位图都保持矢量，可全本地写盘

## 🧭 界面

- **7 个主菜单**：文件 / 编辑 / 对象 / 文字 / 视图 / 窗口 / 帮助，文字与窗口操作不用再翻右侧面板找。
- **7 组双列工具轨**：选择、路径与笔、修形、颜色、形状、画板、视图；悬停有“工具名 + 快捷键”。
- **上下文选项栏**：当前工具、已选数量、画板尺寸、填充/描边、网格与吸附跟着工具走，不再堆一排死按钮。
- **圆形工具**：`⇧L` 进入，默认两点定直径；选项栏“从中心”改第一点为圆心，Shift 锁 45°，Alt 按当前标尺刻度取整直径；两次点击落圆，点首点后再拖过第三点可用三点定圆。
- **路径精准插件**：对象菜单“插件 · 路径精准工具 → 添加内切圆”，或选中闭合路径后在属性坞“路径效果”点“内切圆”，按最大内部间隙落一个贴边活圆，支持复合路径孔洞与一次撤销。
- **画板裁剪与提速**：对象拖出画板后只在板内显示，选择框、缩放手柄、旋转柄和锚点也不越过板边；板外灰色粘贴板点击不命中隐藏对象，框选也不会把它们收进来。粘贴板点阵、画板纸面/阴影与网格走离屏缓存，视口外节点剔除，完全在板外的节点直接跳过，1500 个板外节点 20 帧从 `407.4ms` 降到 `23.3ms`，600 个视口内板外节点从 `199.9ms` 降到 `10.5ms`。
- **可收起右侧面板**：属性 / 图层分页停靠，收起后画布自动补位并保持画板居中；画布右键直接出对象菜单。
- **有呼吸的过渡**：欢迎页进入编辑器的淡入、关闭文档的退场、面板开合和图层切换都有短过渡，`prefers-reduced-motion` 下自动收敛。

## ❓ 常见问题

**为什么自己做而不用 Inkscape？**
Inkscape 很强，但界面老、中文体验一般、GTK 手感和 Windows 原生不搭。Vexa 从第一天就是全中文、Windows 优先、按小方工作室的手感标准来做的。

**什么时候能用上？**
立项规格已定稿，进展看仓库动态。

**名字什么意思？**
VECtor + 家族后缀 -a，和 Chit、Scheda、Kinexa 一个命名家族。
